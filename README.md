# 🦝 GRC Learning Labs

Hands-on Governance, Risk, and Compliance (GRC) learning labs focused on developing practical skills in risk management, security controls, evidence review, compliance, control testing, and IT audit.

## 📌 About This Repository

This repository documents my progression through practical GRC exercises designed to develop the skills used in real-world governance, risk, compliance, and IT audit work.

These are smaller learning labs used to practice individual GRC concepts and analyst workflows. Larger assessments and portfolio projects are maintained in separate repositories.

My approach throughout these labs is:

**Requirement → Control → Evidence → Test → Finding → Risk → Remediation → Validation**

## 💼 Professional Documentation

Where appropriate, each lab includes a professional-style GRC artifact in addition to the learning documentation.

These artifacts are designed to demonstrate how the results of an assessment could be documented in a professional environment, including:

- Control assessment workpapers
- Evidence review documentation
- Risk documentation
- Findings and recommendations
- Remediation tracking
- Assessment conclusions

All scenarios, organizations, systems, evidence, and findings used in these learning labs are simulated unless otherwise stated.

## 🎯 Portfolio Purpose

The purpose of this repository is to demonstrate the development of practical GRC skills through hands-on application rather than certification study alone.

The labs progress from foundational exercises into increasingly realistic assessment, evidence review, risk analysis, and compliance scenarios.
